# 📊 Projeto de Planejamento Financeiro

Projeto desenvolvido como parte de um desafio da **DIO (Digital Innovation One)**, com foco na organização de dados financeiros, definição de estratégias de investimento e visualização de projeções patrimoniais.

---

## 🎯 Objetivo do Projeto

Demonstrar, de forma prática, um modelo de planejamento financeiro contendo:
- Definição do perfil do investidor
- Estratégia de aportes
- Projeção de crescimento patrimonial
- Análise visual por meio de tabelas e gráficos

---

## 🖼️ 1. Banner
Banner de apresentação e identidade visual do projeto.

## 👤 2. Parâmetros do Investidor
Tabela contendo as informações base do investidor, utilizadas para o cálculo e planejamento financeiro.

- Receita mensal  
- Percentual de alocação  
- Taxa de renda esperada  
- Capacidade de investimento  


## 💰 3. Plano de Aportes
Estratégia definida para os aportes mensais, considerando horizonte de tempo e taxa projetada.

## 📈 4. Projeção Patrimonial
Projeção do crescimento do patrimônio ao longo do tempo com base nos aportes realizados.

## 🏦 5. Renda Passiva Estimada
Estimativa da renda passiva futura gerada a partir do patrimônio acumulado.

## ♟️ 6. Cenário Estratégico
Análise de cenários financeiros considerando diferentes estratégias de investimento.

## 🧩 7. Perfil de Distribuição Estratégica
Distribuição dos investimentos por classe de ativos, respeitando o perfil do investidor.

## 📊 8. Gráfico de Barra
Visualização gráfica comparativa dos dados financeiros.


## 🛠️ Tecnologias Utilizadas
- Planilha eletrônica (Excel / Google Sheets)
- Git e GitHub
- Markdown


## 📌 Considerações Finais
Este projeto tem caráter educacional e foi desenvolvido para consolidar conceitos de planejamento financeiro e organização de informações, conforme os objetivos propostos pela DIO.
